Overview

This is the site you are on right now. It is a multi-page portfolio that introduces me, shows the skills I have built this term, and gives a way to reach me. I built it step by step: starting with a proposal, then real content, then wireframes, then a design system, and finally the working code.

Skills & Tools Used

  • HTML
  • CSS
  • Responsive Design
  • Accessibility Basics
  • GitHub Pages

What I Learned

Building this site taught me that good design starts long before code. I learned to plan first: write a proposal, plan the content, sketch a wireframe, and set design tokens, before touching HTML or CSS. That order made the coding step faster and cleaner.

I also learned how to build a layout that works on a phone and a full-size screen, and how small choices, like color contrast and spacing, add up to something that looks designed instead of thrown together.

Next time, I would like to start gathering my own project screenshots earlier, instead of using a placeholder image while I wait for the site to go live.
